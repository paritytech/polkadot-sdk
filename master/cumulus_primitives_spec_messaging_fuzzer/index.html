Fuzzer for cumulus_primitives_spec_messaging: the MMR verifiers in lift, the frontier in mmr (frontier) and the off-chain response verifiers in message (message).

Oracle keeps one real N-leaf MMR, every honest proof over it, and a palette of real hashes for inputs to replay. Inputs are honest proofs with edits applied, or raw bytes. Whenever a verifier returns a real root, the oracle checks the claim behind it:

  • FORGERY: a false claim got through.
  • MALLEABLE: a true claim, but from a non-canonical proof.

Any other panic is the verifier crashing on bad input.

§Running

From this directory: cargo hfuzz run <target>, one of the binaries in src/bin. Pass honggfuzz flags through HFUZZ_RUN_ARGS, e.g. -n 8. Needs binutils-dev and libunwind-dev.

To debug a crash: cargo hfuzz run-debug lift_extension hfuzz_workspace/lift_extension/*.fuzz.
