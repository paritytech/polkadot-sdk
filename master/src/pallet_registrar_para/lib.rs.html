18//! # Parachain registrar pallet
19//!
20//! The user-facing half of parachain registration. It hands out para ids, takes the manager's
21//! deposits as [`Consideration`] tickets, and coordinates the registration itself asynchronously
22//! with the chain that owns the parachain registry.
23//!
24//! Both directions of that coordination are abstract: requests go out through [`SendToRelay`],
25//! verdicts come back in through [`Pallet::receive`], gated by [`Config::RelayOrigin`]. Nothing
26//! here depends on XCM or on the other chain's extrinsics.
27//!
28//! ## Registration flow
29//!
30//! Registration takes two transactions on two chains. Sending a multi-megabyte validation code
31//! through the messaging layer would be wasteful, so this chain only commits to its hash and
32//! length and the blob is uploaded to the relay chain directly:
33//!
34//! 1. [`Pallet::reserve`] allocates a para id here and takes [`Config::ReservationConsideration`].
35//! 2. [`Pallet::register`] takes [`Config::RegistrationConsideration`] for the head data and the
36//!    *declared* code length, then asks the relay chain to accept the registration. Only the code
37//!    hash and length are sent.
38//! 3. The manager uploads the validation code to the relay chain, which accepts it only if it
39//!    matches the hash and length committed to in step 2.
40//! 4. The verdict arrives back as [`Pallet::receive`], which either finalises the registration or
41//!    releases the registration deposit.
42//!
43//! ## Giving up
44//!
45//! Nothing on the relay chain times a registration out, so a request whose code never turns up
46//! waits until the manager ends it with [`Pallet::cancel_registration`]. That asks the relay chain
47//! to drop the authorization and only releases the deposit once it confirms, which is what
48//! keeps a cancellation from freeing the deposit on a para that did register after all.
49//!
50//! ## Locking
51//!
52//! [`Pallet::add_lock`] shuts the manager out of a registered para, leaving it to the para's own
53//! governance. Only root or the para itself can lift it again with [`Pallet::remove_lock`].
54//!
55//! A para is also locked the first time the relay chain reports that it produced a head, which
56//! arrives as [`MessageToParaV1::HeadNoted`]. A lock lifted with [`Pallet::remove_lock`] outranks
57//! that, so it is never re-applied.
58//!
59//! Deposits only ever live on this chain; the relay chain takes nothing.

94/// Block number used for registration deadlines.
95///
96/// On a parachain, configure [`Config::BlockNumberProvider`] to
97/// `cumulus_pallet_parachain_system::RelaychainDataProvider`, so deadlines are expressed in
98/// relay-chain blocks and keep their meaning through a stall in this chain's own block production.
99pub type ProvidedBlockNumberOf<T> =
100	<<T as Config>::BlockNumberProvider as BlockNumberProvider>::BlockNumber;
101
102/// Used to send an XCM `Transact` to the registrar pallet on the remote relay chain.
103pub trait SendToRelay {
104	/// The account id used to identify a registration's manager on both chains.
105	type AccountId;
106
107	/// Send `message` to the relay chain.
108	///
109	/// `Err(())` means the message could not be handed to the transport at all. Callers are
110	/// expected to fail the whole extrinsic, so nothing is left half-done.
111	#[allow(clippy::result_unit_err)]
112	fn send(message: MessageToRelay<Self::AccountId>) -> Result<(), ()>;
113}
114
115#[cfg(feature = "std")]
116impl SendToRelay for () {
117	type AccountId = sp_runtime::AccountId32;
118
119	fn send(_message: MessageToRelay<Self::AccountId>) -> Result<(), ()> {
120		Ok(())
121	}
122}

124/// Where a para id sits in the registration flow.
125#[derive(
126	Encode, Decode, DecodeWithMemTracking, Clone, Eq, PartialEq, Debug, TypeInfo, MaxEncodedLen,
127)]
128pub enum RegistrationState<Ticket, BlockNumber> {
129	/// The para id is held by its manager, but nothing is registered on the relay chain yet.
130	Reserved,
131	/// The relay chain has been asked to register this para and has not reported back.
132	Pending {
133		/// The registration's [`Consideration`] ticket, returned if the registration fails.
134		ticket: Ticket,
135		/// The block from which the manager may give up on this registration.
136		///
137		/// Expressed in [`Config::BlockNumberProvider`] blocks. Long enough that a verdict already
138		/// on its way arrives first, so a cancellation is only ever sent for a registration that
139		/// really has gone quiet. Pushed out again by every [`Pallet::cancel_registration`], so a
140		/// cancellation that gets lost can be retried but not spammed.
141		cancellable_at: BlockNumber,
142	},
143	/// The relay chain has onboarded this para.
144	Registered {
145		/// The registration's [`Consideration`] ticket, kept while the para is registered.
146		ticket: Ticket,
147	},
148}

150/// Everything this chain knows about one para id.
151#[derive(
152	Encode, Decode, DecodeWithMemTracking, Clone, Eq, PartialEq, TypeInfo, MaxEncodedLen, Debug,
153)]
154pub struct ParaInfo<AccountId, ReservationTicket, RegistrationTicket, BlockNumber> {
155	/// The account that reserved the para id and controls it.
156	pub manager: AccountId,
157	/// The [`Consideration`] ticket for the para id itself.
158	pub reservation: ReservationTicket,
159	/// Where this para id sits in the registration flow.
160	pub state: RegistrationState<RegistrationTicket, BlockNumber>,
161	/// Whether the manager is locked out of controlling this para. `None` until the lock is set
162	/// for the first time, and read as unlocked.
163	pub locked: Option<bool>,
164}

169	/// Whether the manager is locked out of this para.
170	pub fn is_locked(&self) -> bool {
171		self.locked.unwrap_or(false)
172	}
173}

189	#[pallet::config]
190	pub trait Config: frame_system::Config {
191		/// The cost of reserving a para id. The footprint is a single zero-sized item, so a flat
192		/// price fits.
193		type ReservationConsideration: Consideration<Self::AccountId, Footprint>;
194
195		/// The cost of a registration, on top of the reservation. The footprint is one item sized
196		/// as head data plus *declared* code length, so a per-byte price fits.
197		type RegistrationConsideration: Consideration<Self::AccountId, Footprint>;
198
199		/// Sends messages to the relay chain.
200		type SendToRelay: SendToRelay<AccountId = Self::AccountId>;
201
202		/// An origin that is sure to be the relay chain's registrar pallet.
203		type RelayOrigin: EnsureOrigin<Self::RuntimeOrigin>;
204
205		/// An origin a parachain uses to act as itself, resolved to its para id.
206		type ParachainOrigin: EnsureOrigin<Self::RuntimeOrigin, Success = ParaId>;
207
208		/// The lowest para id this pallet will hand out.
209		///
210		/// Mirrors the relay chain's `LOWEST_PUBLIC_ID`. Ids below it are reserved for system
211		/// parachains and are not obtainable here.
212		#[pallet::constant]
213		type FirstPublicParaId: Get<ParaId>;
214
215		/// The smallest validation code the relay chain will accept.
216		///
217		/// A local mirror of the relay chain's `MIN_CODE_SIZE`, used to fail early. The relay
218		/// chain checks the real thing against its own live configuration.
219		#[pallet::constant]
220		type MinCodeSize: Get<u32>;
221
222		/// The largest validation code the relay chain will accept.
223		///
224		/// A local mirror of the relay chain's `max_code_size`. See [`Config::MinCodeSize`].
225		#[pallet::constant]
226		type MaxCodeSize: Get<u32>;
227
228		/// The largest head data the relay chain will accept.
229		///
230		/// A local mirror of the relay chain's `max_head_data_size`. See [`Config::MinCodeSize`].
231		#[pallet::constant]
232		type MaxHeadDataSize: Get<u32>;
233
234		/// How long a manager waits for the relay chain before giving up on a registration.
235		///
236		/// Measured in [`Config::BlockNumberProvider`] blocks. Should comfortably cover a round
237		/// trip, so that a verdict that is merely slow lands before anybody tries to cancel.
238		#[pallet::constant]
239		type PendingDeadline: Get<ProvidedBlockNumberOf<Self>>;
240
241		/// Source of block numbers for registration deadlines.
242		///
243		/// On a parachain this should be
244		/// `cumulus_pallet_parachain_system::RelaychainDataProvider`, so
245		/// [`Config::PendingDeadline`] is in relay-chain blocks.
246		type BlockNumberProvider: BlockNumberProvider;
247
248		/// Weight information for the extrinsics in this pallet.
249		type WeightInfo: WeightInfo;
250	}

284		/// A para id was reserved.
285		Reserved { para_id: ParaId, who: T::AccountId },
286		/// A registration was requested and the relay chain has been asked to accept it.

288		/// The relay chain confirmed a registration.

290		/// The relay chain rejected a registration. The registration consideration was returned.
291		RegistrationFailed {
292			para_id: ParaId,
293			message_id: u64,
294			manager: T::AccountId,
295			reason: FailureReason,
296		},
297		/// A manager gave up on a pending registration, and the relay chain has been asked to
298		/// drop the authorization. The consideration stays taken until it answers.
299		CancelRequested { para_id: ParaId, message_id: u64, manager: T::AccountId },
300		/// The relay chain confirmed a cancellation. The registration consideration was returned.
301		RegistrationCancelled { para_id: ParaId, message_id: u64, manager: T::AccountId },
302		/// The manager is locked out of this para.
303		ParaLocked { para_id: ParaId },
304		/// The manager may control this para again.
305		ParaUnlocked { para_id: ParaId },
306		/// Something that should never happen did. The pallet carried on regardless.
307		Unexpected(UnexpectedKind),
308	}

376	#[pallet::call]
377	impl<T: Config> Pallet<T> {
378		/// Accept a report from the relay chain's registrar pallet.
379		///
380		/// Not callable by users: the origin must be the relay chain.
381		#[pallet::call_index(0)]
382		#[pallet::weight(T::WeightInfo::receive())]
383		pub fn receive(origin: OriginFor<T>, message: MessageToPara) -> DispatchResult {
384			T::RelayOrigin::ensure_origin_or_root(origin)?;
385
386			match message {
387				MessageToPara::V1(MessageToParaV1::RegisterResponse {
388					para_id,
389					message_id,
390					outcome,
391				}) => Self::on_register_response(para_id, message_id, outcome),
392				MessageToPara::V1(MessageToParaV1::CancelResponse {
393					para_id,
394					message_id,
395					outcome,
396				}) => Self::on_cancel_response(para_id, message_id, outcome),
397				MessageToPara::V1(MessageToParaV1::HeadNoted { para_id }) => {
398					Self::on_head_noted(para_id)
399				},
400			}
401		}
402
403		/// Reserve the next free para id for the caller.
404		///
405		/// Takes [`Config::ReservationConsideration`]. The caller becomes the manager of the new
406		/// id and is the only account that may [`Pallet::register`] against it.
407		#[pallet::call_index(1)]
408		#[pallet::weight(T::WeightInfo::reserve())]
409		pub fn reserve(origin: OriginFor<T>) -> DispatchResult {
410			let who = ensure_signed(origin)?;
411
412			let para_id = NextFreeParaId::<T>::get().max(T::FirstPublicParaId::get());
413			let next = para_id.checked_add(1).ok_or(Error::<T>::NoFreeParaId)?;
414			ensure!(!Paras::<T>::contains_key(para_id), Error::<T>::AlreadyRegistered);
415
416			let reservation = T::ReservationConsideration::new(&who, Footprint::from_parts(1, 0))?;
417
418			Paras::<T>::insert(
419				para_id,
420				ParaInfo {
421					manager: who.clone(),
422					reservation,
423					state: RegistrationState::Reserved,
424					locked: None,
425				},
426			);
427			NextFreeParaId::<T>::put(next);
428
429			Self::deposit_event(Event::Reserved { para_id, who });
430			Ok(())
431		}
432
433		/// Ask the relay chain to register head data and validation code for a reserved para id.
434		///
435		/// The validation code itself stays here: only `code_hash` and `code_len` are sent. The
436		/// caller uploads the blob to the relay chain separately, which accepts it only if it
437		/// hashes to `code_hash` and is exactly `code_len` bytes long.
438		///
439		/// ## Costs
440		///
441		/// Takes [`Config::RegistrationConsideration`] for the head data and the *declared* code
442		/// length, on top of the para id reservation. It is returned if the relay chain rejects
443		/// the registration or if the caller later abandons it.
444		#[pallet::call_index(2)]
445		#[pallet::weight(T::WeightInfo::register(genesis_head.len() as u32))]
446		pub fn register(
447			origin: OriginFor<T>,
448			para_id: ParaId,
449			genesis_head: Vec<u8>,
450			code_len: u32,
451			code_hash: H256,
452		) -> DispatchResult {
453			let who = ensure_signed(origin)?;
454
455			let mut info = Paras::<T>::get(para_id).ok_or(Error::<T>::NotReserved)?;
456			ensure!(info.manager == who, Error::<T>::NotOwner);
457			ensure!(
458				matches!(info.state, RegistrationState::Reserved),
459				Error::<T>::AlreadyRegistered
460			);
461
462			let head_len = genesis_head.len() as u32;
463			ensure!(head_len <= T::MaxHeadDataSize::get(), Error::<T>::HeadDataTooLarge);
464			ensure!(code_len >= T::MinCodeSize::get(), Error::<T>::CodeTooSmall);
465			ensure!(code_len <= T::MaxCodeSize::get(), Error::<T>::CodeTooLarge);
466
467			let ticket = T::RegistrationConsideration::new(
468				&who,
469				Self::registration_footprint(head_len, code_len),
470			)?;
471
472			let cancellable_at = T::BlockNumberProvider::current_block_number()
473				.saturating_add(T::PendingDeadline::get());
474			info.state = RegistrationState::Pending { ticket, cancellable_at };
475			Paras::<T>::insert(para_id, info);
476
477			// A transport failure returns `Err` and unwinds everything above, ticket included.
478			let message_id = Self::next_message_id();
479			T::SendToRelay::send(MessageToRelay::V1(MessageToRelayV1::Register {
480				para_id,
481				message_id,
482				manager: who.clone(),
483				genesis_head,
484				code_hash,
485				code_len,
486			}))
487			.map_err(|()| Error::<T>::SendFailed)?;
488
489			Self::deposit_event(Event::RegisterRequested { para_id, message_id, manager: who });
490			Ok(())
491		}
492
493		/// Give up on a registration the relay chain never reported on.
494		///
495		/// Callable from [`Config::PendingDeadline`] blocks after the request. Nothing on the
496		/// relay chain abandons a registration on its own, so this is what ends one whose code
497		/// never turned up, and the manager pays for the round trip rather than every relay-chain
498		/// block paying for a sweep.
499		///
500		/// The deposit is not released here: the relay chain is asked to drop the authorization
501		/// first, and [`Pallet::receive`] releases the deposit when it confirms. Waiting for that
502		/// answer is the point. A registration that did go through, with a verdict that got lost on
503		/// the way here, must not have its deposit refunded, and only the relay chain knows
504		/// which of the two happened.
505		///
506		/// The para id itself stays reserved either way, so the manager can simply try again.
507		#[pallet::call_index(3)]
508		#[pallet::weight(T::WeightInfo::cancel_registration())]
509		pub fn cancel_registration(origin: OriginFor<T>, para_id: ParaId) -> DispatchResult {
510			let who = ensure_signed(origin)?;
511
512			let mut info = Paras::<T>::get(para_id).ok_or(Error::<T>::NotReserved)?;
513			ensure!(info.manager == who, Error::<T>::NotOwner);
514			let RegistrationState::Pending { ticket, cancellable_at } = info.state else {
515				return Err(Error::<T>::NotPending.into());
516			};
517			let now = T::BlockNumberProvider::current_block_number();
518			ensure!(now >= cancellable_at, Error::<T>::CannotCancelYet);
519
520			// Another deadline's grace before the manager may ask again, so a request that goes
521			// missing can be retried without the relay chain being asked once per block.
522			info.state = RegistrationState::Pending {
523				ticket,
524				cancellable_at: now.saturating_add(T::PendingDeadline::get()),
525			};
526			Paras::<T>::insert(para_id, info);
527
528			// A transport failure returns `Err` and unwinds the new deadline with it.
529			let message_id = Self::next_message_id();
530			T::SendToRelay::send(MessageToRelay::V1(MessageToRelayV1::CancelRegistration {
531				para_id,
532				message_id,
533			}))
534			.map_err(|()| Error::<T>::SendFailed)?;
535
536			Self::deposit_event(Event::CancelRequested { para_id, message_id, manager: who });
537			Ok(())
538		}

540		/// Lock a registered para, keeping the manager out of it.
541		#[pallet::call_index(4)]
542		#[pallet::weight(T::WeightInfo::add_lock())]
543		pub fn add_lock(origin: OriginFor<T>, para_id: ParaId) -> DispatchResult {
544			let mut info = Paras::<T>::get(para_id).ok_or(Error::<T>::NotReserved)?;
545			Self::ensure_root_para_or_manager(origin, para_id, &info)?;
546			ensure!(!info.is_locked(), Error::<T>::AlreadyLocked);
547			ensure!(
548				matches!(info.state, RegistrationState::Registered { .. }),
549				Error::<T>::NotRegistered
550			);
551
552			info.locked = Some(true);
553			Paras::<T>::insert(para_id, info);
554
555			Self::deposit_event(Event::ParaLocked { para_id });
556			Ok(())
557		}
558
559		/// Unlock a para, handing control back to the manager.
560		///
561		/// The manager is not accepted here: a lock it could lift would not be a lock.
562		#[pallet::call_index(5)]
563		#[pallet::weight(T::WeightInfo::remove_lock())]
564		pub fn remove_lock(origin: OriginFor<T>, para_id: ParaId) -> DispatchResult {
565			Self::ensure_root_or_para(origin, para_id)?;
566			let mut info = Paras::<T>::get(para_id).ok_or(Error::<T>::NotReserved)?;
567			ensure!(info.is_locked(), Error::<T>::NotLocked);
568
569			info.locked = Some(false);
570			Paras::<T>::insert(para_id, info);
571
572			Self::deposit_event(Event::ParaUnlocked { para_id });
573			Ok(())
574		}
575	}
576}

578impl<T: Config> Pallet<T> {
579	/// The footprint a registration is charged for: the head data plus the *declared* code length.
580	pub fn registration_footprint(head_len: u32, code_len: u32) -> Footprint {
581		Footprint::from_parts(1, head_len.saturating_add(code_len) as usize)
582	}
583
584	/// Ensure `origin` may manage `para_id`: the para itself, its manager while unlocked, or root.
585	fn ensure_root_para_or_manager(
586		origin: frame_system::pallet_prelude::OriginFor<T>,
587		para_id: ParaId,
588		info: &ParaInfoOf<T>,
589	) -> DispatchResult {
590		if let Ok(id) = T::ParachainOrigin::ensure_origin(origin.clone()) {
591			ensure!(id == para_id, Error::<T>::NotOwner);
592			return Ok(());
593		}
594		if let Ok(who) = frame_system::ensure_signed(origin.clone()) {
595			ensure!(who == info.manager, Error::<T>::NotOwner);
596			ensure!(!info.is_locked(), Error::<T>::ParaLocked);
597			return Ok(());
598		}
599		frame_system::ensure_root(origin)?;
600		Ok(())
601	}
602
603	/// Ensure `origin` is root or `para_id` itself.
604	fn ensure_root_or_para(
605		origin: frame_system::pallet_prelude::OriginFor<T>,
606		para_id: ParaId,
607	) -> DispatchResult {
608		if frame_system::ensure_root(origin.clone()).is_ok() {
609			return Ok(());
610		}
611		let id = T::ParachainOrigin::ensure_origin(origin)?;
612		ensure!(id == para_id, Error::<T>::NotOwner);
613		Ok(())
614	}
615
616	/// Report a failed defensive check: loud in the logs, and visible on chain.
617	fn report_unexpected(kind: UnexpectedKind) {
618		log::error!(target: "runtime::registrar-para", "unexpected: {kind:?}");
619		Self::deposit_event(Event::Unexpected(kind));
620	}
621
622	/// Take the id for the next message to the relay chain.
623	fn next_message_id() -> u64 {
624		NextMessageId::<T>::mutate(|next| {
625			let id = *next;
626			*next = next.wrapping_add(1);
627			id
628		})
629	}
630
631	/// Apply the relay chain's verdict on a registration.
632	///
633	/// A response about a para id we are not expecting one for is dropped rather than treated as a
634	/// dispatch error: erroring here would unwind the whole incoming message for something we can
635	/// do nothing about anyway. They are reported as [`Event::Unexpected`] instead.
636	fn on_register_response(para_id: ParaId, message_id: u64, outcome: Outcome) -> DispatchResult {
637		let Some(mut info) = Paras::<T>::get(para_id) else {
638			Self::report_unexpected(UnexpectedKind::RegisterResponseForUnknownPara {
639				para_id,
640				message_id,
641			});
642			return Ok(());
643		};
644		let RegistrationState::Pending { ticket, .. } = info.state else {
645			Self::report_unexpected(UnexpectedKind::RegisterResponseNotPending {
646				para_id,
647				message_id,
648			});
649			return Ok(());
650		};
651
652		let manager = info.manager.clone();
653		match outcome {
654			Ok(()) => {
655				info.state = RegistrationState::Registered { ticket };
656				Paras::<T>::insert(para_id, info);
657				Self::deposit_event(Event::Registered { para_id, message_id, manager });
658			},
659			Err(reason) => {
660				ticket.drop(&info.manager)?;
661				info.state = RegistrationState::Reserved;
662				Paras::<T>::insert(para_id, info);
663				Self::deposit_event(Event::RegistrationFailed {
664					para_id,
665					message_id,
666					manager,
667					reason,
668				});
669			},
670		}
671
672		Ok(())
673	}
674
675	/// Lock a para the relay chain has seen produce a head.
676	fn on_head_noted(para_id: ParaId) -> DispatchResult {
677		let Some(mut info) = Paras::<T>::get(para_id) else {
678			Self::report_unexpected(UnexpectedKind::HeadNotedForUnknownPara { para_id });
679			return Ok(());
680		};
681
682		if info.locked.is_some() {
683			return Ok(());
684		}
685
686		if !matches!(info.state, RegistrationState::Registered { .. }) {
687			Self::report_unexpected(UnexpectedKind::HeadNotedForUnregisteredPara { para_id });
688		}
689
690		info.locked = Some(true);
691		Paras::<T>::insert(para_id, info);
692
693		Self::deposit_event(Event::ParaLocked { para_id });
694
695		Ok(())
696	}
697
698	/// Apply the relay chain's answer to a cancellation.
699	///
700	/// `Ok(())` means the authorization is gone, so the deposit goes back. The one refusal is
701	/// [`FailureReason::AlreadyRegistered`]: the code landed after all and the earlier verdict was
702	/// simply lost, so the para is recorded as registered and the deposit stays held.
703	///
704	/// Unlike a register response, an answer for a para that is no longer pending is expected
705	/// rather than unexpected: a verdict already in flight when the cancellation was sent settles
706	/// the registration first, and this then has nothing left to do.
707	fn on_cancel_response(para_id: ParaId, message_id: u64, outcome: Outcome) -> DispatchResult {
708		let Some(mut info) = Paras::<T>::get(para_id) else {
709			Self::report_unexpected(UnexpectedKind::CancelResponseForUnknownPara {
710				para_id,
711				message_id,
712			});
713			return Ok(());
714		};
715		let RegistrationState::Pending { ticket, .. } = info.state else {
716			log::debug!(
717				target: "runtime::registrar-para",
718				"cancel response for para {para_id} which is no longer pending, dropping",
719			);
720			return Ok(());
721		};
722
723		let manager = info.manager.clone();
724		match outcome {
725			Ok(()) => {
726				ticket.drop(&info.manager)?;
727				info.state = RegistrationState::Reserved;
728				Paras::<T>::insert(para_id, info);
729				Self::deposit_event(Event::RegistrationCancelled { para_id, message_id, manager });
730			},
731			Err(FailureReason::AlreadyRegistered) => {
732				info.state = RegistrationState::Registered { ticket };
733				Paras::<T>::insert(para_id, info);
734				Self::deposit_event(Event::Registered { para_id, message_id, manager });
735			},
736			// Nothing else is a cancellation the relay chain refuses, so leave the registration
737			// pending: the manager can ask again once the deadline comes round.
738			Err(reason) => {
739				Self::report_unexpected(UnexpectedKind::CancelRefused {
740					para_id,
741					message_id,
742					reason,
743				});
744			},
745		}
746
747		Ok(())
748	}
