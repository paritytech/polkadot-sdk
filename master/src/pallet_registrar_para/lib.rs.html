18//! # Parachain registrar pallet
19//!
20//! The user-facing half of parachain registration. It hands out para ids, takes the manager's
21//! deposits as [`Consideration`] tickets, and coordinates the registration itself asynchronously
22//! with the chain that owns the parachain registry.
23//!
24//! Both directions of that coordination are abstract: requests go out through [`SendToRelay`],
25//! verdicts come back in through [`Pallet::receive`], gated by [`Config::RelayOrigin`]. Nothing
26//! here depends on XCM or on the other chain's extrinsics.
27//!
28//! ## Registration flow
29//!
30//! Registration takes two transactions on two chains. Sending a multi-megabyte validation code
31//! through the messaging layer would be wasteful, so this chain only commits to its hash and
32//! length and the blob is uploaded to the relay chain directly:
33//!
34//! 1. [`Pallet::reserve`] allocates a para id here and takes [`Config::ReservationConsideration`].
35//! 2. [`Pallet::register`] takes [`Config::RegistrationConsideration`] for the head data and a
36//!    full-sized validation code, then asks the relay chain to accept the registration. Only the
37//!    code hash and length are sent.
38//! 3. The manager uploads the validation code to the relay chain, which accepts it only if it
39//!    matches the hash and length committed to in step 2.
40//! 4. The verdict arrives back as [`Pallet::receive`], which either finalises the registration or
41//!    releases the registration deposit.
42//!
43//! ## Giving up
44//!
45//! Nothing on the relay chain times a registration out, so a request whose code never turns up
46//! waits until the manager ends it with [`Pallet::cancel_registration`]. That asks the relay chain
47//! to drop the authorization and only releases the deposit once it confirms, which is what
48//! keeps a cancellation from freeing the deposit on a para that did register after all.
49//!
50//! ## Giving up a para id
51//!
52//! [`Pallet::deregister`] on an id that is only reserved releases the reservation right away, as
53//! the relay chain never heard of it. A registered para has to be dropped on the relay chain
54//! first, so both deposits stay held until it answers. If the answer never arrives, the manager
55//! calls [`Pallet::deregister`] again.
56//!
57//! ## Forcing
58//!
59//! [`Pallet::force_register`] is the same request from [`Config::ForceOrigin`], for an id that need
60//! not have been reserved first. The manager still pays, unless the id is a system one or the
61//! origin passes `skip_deposit`. A system id whose registration falls through is dropped, not kept
62//! reserved.
63//!
64//! ## Locking
65//!
66//! [`Pallet::add_lock`] shuts the manager out of a registered para, leaving it to the para's own
67//! governance. Only root or the para itself can lift it again with [`Pallet::remove_lock`].
68//!
69//! A para is also locked the first time the relay chain reports that it produced a head, which
70//! arrives as [`MessageToParaV1::HeadNoted`]. A lock lifted with [`Pallet::remove_lock`] outranks
71//! that, so it is never re-applied.
72//!
73//! Deposits only ever live on this chain; the relay chain takes nothing.

109/// Block number used for registration deadlines.
110///
111/// On a parachain, configure [`Config::BlockNumberProvider`] to
112/// `cumulus_pallet_parachain_system::RelaychainDataProvider`, so deadlines are expressed in
113/// relay-chain blocks and keep their meaning through a stall in this chain's own block production.
114pub type ProvidedBlockNumberOf<T> =
115	<<T as Config>::BlockNumberProvider as BlockNumberProvider>::BlockNumber;

117/// Used to send an XCM `Transact` to the registrar pallet on the remote relay chain.
118pub trait SendToRelay {
119	/// The account id used to identify a registration's manager on both chains.
120	type AccountId;
121
122	/// Send `message` to the relay chain.
123	///
124	/// `Err(())` means the message could not be handed to the transport at all. Callers are
125	/// expected to fail the whole extrinsic, so nothing is left half-done.
126	#[allow(clippy::result_unit_err)]
127	fn send(message: MessageToRelay<Self::AccountId>) -> Result<(), ()>;
128}

132	type AccountId = sp_runtime::AccountId32;
133
134	fn send(_message: MessageToRelay<Self::AccountId>) -> Result<(), ()> {
135		Ok(())
136	}
137}

146/// Where a para id sits in the registration flow.
147#[derive(
148	Encode, Decode, DecodeWithMemTracking, Clone, Eq, PartialEq, Debug, TypeInfo, MaxEncodedLen,
149)]
150pub enum RegistrationState<Ticket, BlockNumber> {
151	/// The para id is held by its manager, but nothing is registered on the relay chain yet.
152	Reserved,
153	/// The relay chain has been asked to register this para and has not reported back.
154	Pending {
155		/// The registration's [`Consideration`] ticket, returned if the registration fails.
156		/// `None` if [`Pallet::force_register`] skipped the deposit.
157		ticket: Option<Ticket>,
158		/// The block from which the manager may give up on this registration.
159		///
160		/// Expressed in [`Config::BlockNumberProvider`] blocks. Long enough that a verdict already
161		/// on its way arrives first, so a cancellation is only ever sent for a registration that
162		/// really has gone quiet. Pushed out again by every [`Pallet::cancel_registration`], so a
163		/// cancellation that gets lost can be retried but not spammed.
164		cancellable_at: BlockNumber,
165		/// The request this state is waiting on; a response carrying any other id is stale.
166		message_id: u64,
167	},
168	/// The relay chain has onboarded this para.
169	Registered {
170		/// The registration's [`Consideration`] ticket, kept while the para is registered.
171		ticket: Option<Ticket>,
172	},
173	/// The relay chain has been asked to drop this para and has not reported back.
174	///
175	/// Both deposits stay held: only the relay chain knows whether the para really went away, and
176	/// a refusal puts it straight back to [`RegistrationState::Registered`].
177	///
178	/// There is nothing to cancel from here: if no answer turns up, the manager calls
179	/// [`Pallet::deregister`] again once `can_retry_after` has passed.
180	Deregistering {
181		/// The registration's [`Consideration`] ticket, released once the relay chain confirms.
182		ticket: Option<Ticket>,
183		/// The block from which the manager may send the [`MessageToRelayV1::Deregister`] again,
184		/// if the answer never arrived. Retrying reports the missing answer as
185		/// [`UnexpectedKind::ResponseNeverArrived`].
186		can_retry_after: BlockNumber,
187		/// The request this state is waiting on; a response carrying any other id is stale.
188		message_id: u64,
189	},
190}

192/// Everything this chain knows about one para id.
193#[derive(
194	Encode, Decode, DecodeWithMemTracking, Clone, Eq, PartialEq, TypeInfo, MaxEncodedLen, Debug,
195)]
196pub struct ParaInfo<AccountId, ReservationTicket, RegistrationTicket, BlockNumber> {
197	/// The account that reserved the para id and controls it.
198	pub manager: AccountId,
199	/// The [`Consideration`] ticket for the para id itself. `None` if
200	/// [`Pallet::force_register`] skipped the deposit.
201	pub reservation: Option<ReservationTicket>,
202	/// Where this para id sits in the registration flow.
203	pub state: RegistrationState<RegistrationTicket, BlockNumber>,
204	/// Whether the manager is locked out of controlling this para. `None` until the lock is set
205	/// for the first time, and read as unlocked.
206	pub locked: Option<bool>,
207}

212	/// Whether the manager is locked out of this para.

214		self.locked.unwrap_or(false)
215	}
216}

232	#[pallet::config]
233	pub trait Config: frame_system::Config {
234		/// The cost of reserving a para id. The footprint is a single zero-sized item, so a flat
235		/// price fits.
236		type ReservationConsideration: Consideration<Self::AccountId, Footprint>;
237
238		/// The cost of a registration, on top of the reservation. The footprint is one item sized
239		/// as head data plus the relay chain's `max_code_size`, so a per-byte price fits.
240		type RegistrationConsideration: Consideration<Self::AccountId, Footprint>;
241
242		/// Sends messages to the relay chain.
243		type SendToRelay: SendToRelay<AccountId = Self::AccountId>;
244
245		/// An origin that is sure to be the relay chain's registrar pallet.
246		type RelayOrigin: EnsureOrigin<Self::RuntimeOrigin>;
247
248		/// An origin a parachain uses to act as itself, resolved to its para id.
249		type ParachainOrigin: EnsureOrigin<Self::RuntimeOrigin, Success = ParaId>;
250
251		/// The origin allowed to call [`Pallet::force_register`].
252		type ForceOrigin: EnsureOrigin<Self::RuntimeOrigin>;
253
254		/// The lowest para id this pallet will hand out.
255		///
256		/// Mirrors the relay chain's `LOWEST_PUBLIC_ID`. Ids below it are reserved for system
257		/// parachains and are not obtainable here.
258		#[pallet::constant]
259		type FirstPublicParaId: Get<ParaId>;
260
261		/// The smallest validation code the relay chain will accept.
262		///
263		/// A local mirror of the relay chain's `MIN_CODE_SIZE`, used to fail early. The relay
264		/// chain checks the real thing against its own live configuration.
265		#[pallet::constant]
266		type MinCodeSize: Get<u32>;
267
268		/// The relay chain's host configuration, `None` until this chain has received it.
269		///
270		/// On a parachain, read `cumulus_pallet_parachain_system::HostConfiguration`.
271		type HostConfiguration: Get<Option<AbridgedHostConfiguration>>;
272
273		/// How long a manager waits for the relay chain before giving up on a registration.
274		///
275		/// Measured in [`Config::BlockNumberProvider`] blocks. Should comfortably cover a round
276		/// trip, so that a verdict that is merely slow lands before anybody tries to cancel.
277		#[pallet::constant]
278		type PendingDeadline: Get<ProvidedBlockNumberOf<Self>>;
279
280		/// Source of block numbers for registration deadlines.
281		///
282		/// On a parachain this should be
283		/// `cumulus_pallet_parachain_system::RelaychainDataProvider`, so
284		/// [`Config::PendingDeadline`] is in relay-chain blocks.
285		type BlockNumberProvider: BlockNumberProvider;
286
287		/// Weight information for the extrinsics in this pallet.
288		type WeightInfo: WeightInfo;
289
290		/// Puts a [`Config::HostConfiguration`] in place for the benchmarks.
291		#[cfg(feature = "runtime-benchmarks")]
292		type BenchmarkHelper: BenchmarkHelper;
293	}

446	#[pallet::call]
447	impl<T: Config> Pallet<T> {
448		/// Accept a report from the relay chain's registrar pallet.
449		///
450		/// Not callable by users: the origin must be the relay chain.
451		#[pallet::call_index(0)]
452		#[pallet::weight(T::WeightInfo::receive())]
453		pub fn receive(origin: OriginFor<T>, message: MessageToPara) -> DispatchResult {
454			T::RelayOrigin::ensure_origin_or_root(origin)?;
455
456			match message {
457				MessageToPara::V1(MessageToParaV1::RegisterResponse {
458					para_id,
459					message_id,
460					outcome,
461				}) => Self::on_register_response(para_id, message_id, outcome),
462				MessageToPara::V1(MessageToParaV1::CancelResponse {
463					para_id,
464					message_id,
465					outcome,
466				}) => Self::on_cancel_response(para_id, message_id, outcome),
467				MessageToPara::V1(MessageToParaV1::DeregisterResponse {
468					para_id,
469					message_id,
470					outcome,
471				}) => Self::on_deregister_response(para_id, message_id, outcome),
472				MessageToPara::V1(MessageToParaV1::CodeUpgradeResponse {
473					para_id,
474					message_id,
475					outcome,
476				}) => Self::on_code_upgrade_response(para_id, message_id, outcome),
477				MessageToPara::V1(MessageToParaV1::CodeUpgradeScheduled {
478					para_id,
479					message_id,
480				}) => Self::on_code_upgrade_scheduled(para_id, message_id),
481				MessageToPara::V1(MessageToParaV1::SetHeadResponse {
482					para_id,
483					message_id,
484					outcome,
485				}) => Self::on_set_head_response(para_id, message_id, outcome),
486				MessageToPara::V1(MessageToParaV1::HeadNoted { para_id }) => {
487					Self::on_head_noted(para_id)
488				},
489			}
490		}
491
492		/// Reserve the next free para id for the caller.
493		///
494		/// Takes [`Config::ReservationConsideration`]. The caller becomes the manager of the new
495		/// id and is the only account that may [`Pallet::register`] against it.
496		#[pallet::call_index(1)]
497		#[pallet::weight(T::WeightInfo::reserve())]
498		pub fn reserve(origin: OriginFor<T>) -> DispatchResult {
499			let who = ensure_signed(origin)?;
500
501			let para_id = NextFreeParaId::<T>::get().max(T::FirstPublicParaId::get());
502			let next = para_id.checked_add(1).ok_or(Error::<T>::NoFreeParaId)?;
503			ensure!(!Paras::<T>::contains_key(para_id), Error::<T>::AlreadyRegistered);
504
505			let reservation =
506				T::ReservationConsideration::new(&who, Self::reservation_footprint())?;
507
508			Paras::<T>::insert(
509				para_id,
510				ParaInfo {
511					manager: who.clone(),
512					reservation: Some(reservation),
513					state: RegistrationState::Reserved,
514					locked: None,
515				},
516			);
517			NextFreeParaId::<T>::put(next);
518
519			Self::deposit_event(Event::Reserved { para_id, who });
520			Ok(())
521		}
522
523		/// Ask the relay chain to register head data and validation code for a reserved para id.
524		///
525		/// The validation code itself stays here: only `code_hash` and `code_len` are sent. The
526		/// caller uploads the blob to the relay chain separately, which accepts it only if it
527		/// hashes to `code_hash` and is exactly `code_len` bytes long.
528		///
529		/// ## Costs
530		///
531		/// Takes [`Config::RegistrationConsideration`] for the head data and a code of the relay
532		/// chain's `max_code_size`, on top of the para id reservation: a para pays for the largest
533		/// code it could ever have on chain, not the one it registers with. It is returned if the
534		/// relay chain rejects the registration or if the caller later abandons it.
535		///
536		/// Ids below [`Config::FirstPublicParaId`] are refused, see [`Pallet::force_register`].
537		#[pallet::call_index(2)]
538		#[pallet::weight(T::WeightInfo::register(genesis_head.len() as u32))]
539		pub fn register(
540			origin: OriginFor<T>,
541			para_id: ParaId,
542			genesis_head: Vec<u8>,
543			code_len: u32,
544			code_hash: H256,
545		) -> DispatchResult {
546			let who = ensure_signed(origin)?;
547			ensure!(!Self::is_system(para_id), Error::<T>::SystemParaId);
548
549			let info = Paras::<T>::get(para_id).ok_or(Error::<T>::NotReserved)?;
550			ensure!(info.manager == who, Error::<T>::NotOwner);
551
552			Self::do_register(para_id, info, genesis_head, code_len, code_hash, false)
553		}
554
555		/// Give up on a registration the relay chain never reported on.
556		///
557		/// Callable from [`Config::PendingDeadline`] blocks after the request. Nothing on the
558		/// relay chain abandons a registration on its own, so this is what ends one whose code
559		/// never turned up, and the manager pays for the round trip rather than every relay-chain
560		/// block paying for a sweep.
561		///
562		/// The deposit is not released here: the relay chain is asked to drop the authorization
563		/// first, and [`Pallet::receive`] releases the deposit when it confirms. Waiting for that
564		/// answer is the point. A registration that did go through, with a verdict that got lost on
565		/// the way here, must not have its deposit refunded, and only the relay chain knows
566		/// which of the two happened.
567		///
568		/// The para id itself stays reserved either way, so the manager can simply try again. A
569		/// system id is dropped instead, as only [`Pallet::force_register`] may register one.
570		#[pallet::call_index(3)]
571		#[pallet::weight(T::WeightInfo::cancel_registration())]
572		pub fn cancel_registration(origin: OriginFor<T>, para_id: ParaId) -> DispatchResult {
573			let who = ensure_signed(origin)?;
574
575			let mut info = Paras::<T>::get(para_id).ok_or(Error::<T>::NotReserved)?;
576			ensure!(info.manager == who, Error::<T>::NotOwner);
577			let RegistrationState::Pending { ticket, cancellable_at, message_id: awaited } =
578				info.state
579			else {
580				return Err(Error::<T>::NotPending.into());
581			};
582			let now = T::BlockNumberProvider::current_block_number();
583			ensure!(now >= cancellable_at, Error::<T>::CannotCancelYet);
584
585			// Getting here means the relay chain's answer to `awaited` never turned up. That should
586			// not happen, so say so on chain instead of quietly retrying.
587			Self::report_unexpected(UnexpectedKind::ResponseNeverArrived {
588				para_id,
589				message_id: awaited,
590			});
591
592			// Another deadline's grace before the manager may ask again, so a request that goes
593			// missing can be retried without the relay chain being asked once per block.
594			let message_id = Self::next_message_id();
595			info.state = RegistrationState::Pending {
596				ticket,
597				cancellable_at: now.saturating_add(T::PendingDeadline::get()),
598				message_id,
599			};
600			Paras::<T>::insert(para_id, info);
601
602			// A transport failure returns `Err` and unwinds the new deadline with it.
603			T::SendToRelay::send(MessageToRelay::V1(MessageToRelayV1::CancelRegistration {
604				para_id,
605				message_id,
606			}))
607			.map_err(|()| Error::<T>::SendFailed)?;
608
609			Self::deposit_event(Event::CancelRequested { para_id, message_id, manager: who });
610			Ok(())
611		}

613		/// Lock a registered para, keeping the manager out of it.
614		#[pallet::call_index(4)]
615		#[pallet::weight(T::WeightInfo::add_lock())]
616		pub fn add_lock(origin: OriginFor<T>, para_id: ParaId) -> DispatchResult {
617			let mut info = Paras::<T>::get(para_id).ok_or(Error::<T>::NotReserved)?;
618			Self::ensure_root_para_or_manager(origin, para_id, &info)?;
619			ensure!(!info.is_locked(), Error::<T>::AlreadyLocked);
620			ensure!(
621				matches!(info.state, RegistrationState::Registered { .. }),
622				Error::<T>::NotRegistered
623			);
624
625			info.locked = Some(true);
626			Paras::<T>::insert(para_id, info);
627
628			Self::deposit_event(Event::ParaLocked { para_id });
629			Ok(())
630		}

649		/// Give up a para id, releasing every consideration held for it.
650		///
651		/// An id that is only reserved is released immediately. A registered para has to be
652		/// dropped on the relay chain first, so the considerations stay taken until it answers.
653		///
654		/// Can be called again on a para that is already deregistering, once `can_retry_after`
655		/// has passed. This resends the request.
656		#[pallet::call_index(6)]
657		#[pallet::weight(
658			T::WeightInfo::deregister_reserved()
659				.max(T::WeightInfo::deregister_registered())
660				.max(T::WeightInfo::deregister_retry())
661		)]
662		pub fn deregister(origin: OriginFor<T>, para_id: ParaId) -> DispatchResult {
663			let mut info = Paras::<T>::get(para_id).ok_or(Error::<T>::NotReserved)?;
664			Self::ensure_root_para_or_manager(origin, para_id, &info)?;
665
666			let manager = info.manager.clone();
667			let now = T::BlockNumberProvider::current_block_number();
668			let ticket = match info.state {
669				// The relay chain never knew this id, so there is nobody to ask.
670				RegistrationState::Reserved => {
671					if let Some(reservation) = info.reservation {
672						reservation.drop(&manager)?;
673					}
674					Paras::<T>::remove(para_id);
675					Self::deposit_event(Event::ReservationDropped { para_id, manager });
676					return Ok(());
677				},
678				RegistrationState::Pending { .. } => return Err(Error::<T>::NotRegistered.into()),
679				RegistrationState::Registered { ticket } => ticket,
680				RegistrationState::Deregistering {
681					ticket,
682					can_retry_after,
683					message_id: awaited,
684				} => {
685					ensure!(now >= can_retry_after, Error::<T>::CannotRetryYet);
686					Self::report_unexpected(UnexpectedKind::ResponseNeverArrived {
687						para_id,
688						message_id: awaited,
689					});
690					ticket
691				},
692			};
693
694			let message_id = Self::next_message_id();
695			info.state = RegistrationState::Deregistering {
696				ticket,
697				can_retry_after: now.saturating_add(T::PendingDeadline::get()),
698				message_id,
699			};
700			Paras::<T>::insert(para_id, info);
701
702			// A transport failure returns `Err` and unwinds the new state with it.
703			T::SendToRelay::send(MessageToRelay::V1(MessageToRelayV1::Deregister {
704				para_id,
705				message_id,
706			}))
707			.map_err(|()| Error::<T>::SendFailed)?;
708
709			Self::deposit_event(Event::DeregisterRequested { para_id, message_id, manager });
710			Ok(())
711		}

738		/// Ask the relay chain to register a para id under `manager`, on [`Config::ForceOrigin`]'s
739		/// say-so.
740		///
741		/// The relay chain's `paras_registrar::force_register`, moved here: the same checks and the
742		/// same deposits, except that the id need not have been reserved first, so the origin can
743		/// onboard an id nobody holds, the system range included.
744		///
745		/// System ids never take a deposit, as on Polkadot, and `skip_deposit` waives it for a
746		/// public id too. A reservation the manager already holds stays held.
747		#[pallet::call_index(9)]
748		#[pallet::weight(T::WeightInfo::force_register(genesis_head.len() as u32))]
749		pub fn force_register(
750			origin: OriginFor<T>,
751			para_id: ParaId,
752			manager: T::AccountId,
753			genesis_head: Vec<u8>,
754			code_len: u32,
755			code_hash: H256,
756			skip_deposit: bool,
757		) -> DispatchResult {
758			T::ForceOrigin::ensure_origin(origin)?;
759			let skip_deposit = skip_deposit || Self::is_system(para_id);
760
761			let info = match Paras::<T>::get(para_id) {
762				Some(info) => {
763					ensure!(info.manager == manager, Error::<T>::NotOwner);
764					ensure!(!info.is_locked(), Error::<T>::ParaLocked);
765					info
766				},
767				// Unreserved ids are the point of this call, so take the reservation now.
768				None => {
769					let reservation = if skip_deposit {
770						None
771					} else {
772						Some(T::ReservationConsideration::new(
773							&manager,
774							Self::reservation_footprint(),
775						)?)
776					};
777					ParaInfo {
778						manager,
779						reservation,
780						state: RegistrationState::Reserved,
781						locked: None,
782					}
783				},
784			};
785
786			Self::do_register(para_id, info, genesis_head, code_len, code_hash, skip_deposit)?;
787
788			// `reserve` errors rather than skipping an id it finds taken, so leaving the counter
789			// behind a forced id would brick it for good.
790			NextFreeParaId::<T>::mutate(|next| *next = (*next).max(para_id.saturating_add(1)));
791			Ok(())
792		}
793	}

802	/// The footprint a registration is charged for: the head data plus a full-sized validation
803	/// code, whatever length the registration itself declares.
804	pub fn registration_footprint(head_len: u32, config: &AbridgedHostConfiguration) -> Footprint {
805		Footprint::from_parts(1, head_len.saturating_add(config.max_code_size) as usize)

808	/// Whether `para_id` is in the system range, below [`Config::FirstPublicParaId`].
809	fn is_system(para_id: ParaId) -> bool {
810		para_id < T::FirstPublicParaId::get()
811	}

813	/// Check the pallet's storage invariants.
814	#[cfg(any(feature = "try-runtime", test))]
815	pub fn do_try_state() -> Result<(), sp_runtime::TryRuntimeError> {
816		for (para_id, info) in Paras::<T>::iter() {
817			let (reserved, ticket) = match &info.state {
818				RegistrationState::Reserved => (true, None),
819				RegistrationState::Pending { ticket, .. } |
820				RegistrationState::Registered { ticket } |
821				RegistrationState::Deregistering { ticket, .. } => (false, ticket.as_ref()),
822			};
823			if Self::is_system(para_id) {
824				ensure!(!reserved, "a system para id is left reserved");
825				ensure!(
826					info.reservation.is_none() && ticket.is_none(),
827					"a system para holds a deposit"
828				);
829			} else if info.reservation.is_none() || (!reserved && ticket.is_none()) {
830				// `skip_deposit` and migrated paras may lack one, so only warn.
831				log::warn!(target: "runtime::registrar-para", "para {para_id} is missing a deposit");
832			}
833		}
834		Ok(())
835	}
836
837	/// Take the registration deposit from `info.manager` and ask the relay chain to register.
838	fn do_register(
839		para_id: ParaId,
840		mut info: ParaInfoOf<T>,
841		genesis_head: Vec<u8>,
842		code_len: u32,
843		code_hash: H256,
844		skip_deposit: bool,
845	) -> DispatchResult {
846		ensure!(matches!(info.state, RegistrationState::Reserved), Error::<T>::AlreadyRegistered);
847
848		let config = T::HostConfiguration::get().ok_or(Error::<T>::NoHostConfiguration)?;
849		let head_len = genesis_head.len() as u32;
850		ensure!(head_len <= config.max_head_data_size, Error::<T>::HeadDataTooLarge);
851		ensure!(code_len >= T::MinCodeSize::get(), Error::<T>::CodeTooSmall);
852		ensure!(code_len <= config.max_code_size, Error::<T>::CodeTooLarge);
853
854		let manager = info.manager.clone();
855		let ticket = if skip_deposit {
856			None
857		} else {
858			Some(T::RegistrationConsideration::new(
859				&manager,
860				Self::registration_footprint(head_len, &config),
861			)?)
862		};
863
864		let cancellable_at = T::BlockNumberProvider::current_block_number()
865			.saturating_add(T::PendingDeadline::get());
866		let message_id = Self::next_message_id();
867		info.state = RegistrationState::Pending { ticket, cancellable_at, message_id };
868		Paras::<T>::insert(para_id, info);
869
870		// A transport failure returns `Err` and unwinds everything above, tickets included.
871		T::SendToRelay::send(MessageToRelay::V1(MessageToRelayV1::Register {
872			para_id,
873			message_id,
874			manager: manager.clone(),
875			genesis_head,
876			code_hash,
877			code_len,
878		}))
879		.map_err(|()| Error::<T>::SendFailed)?;
880
881		Self::deposit_event(Event::RegisterRequested { para_id, message_id, manager });
882		Ok(())
883	}

885	/// Ensure `origin` may manage `para_id`: the para itself, its manager while unlocked, or root.
886	fn ensure_root_para_or_manager(
887		origin: frame_system::pallet_prelude::OriginFor<T>,
888		para_id: ParaId,
889		info: &ParaInfoOf<T>,
890	) -> DispatchResult {
891		if let Ok(id) = T::ParachainOrigin::ensure_origin(origin.clone()) {
892			ensure!(id == para_id, Error::<T>::NotOwner);
893			return Ok(());
894		}
895		if let Ok(who) = frame_system::ensure_signed(origin.clone()) {
896			ensure!(who == info.manager, Error::<T>::NotOwner);
897			ensure!(!info.is_locked(), Error::<T>::ParaLocked);
898			return Ok(());
899		}
900		frame_system::ensure_root(origin)?;
901		Ok(())
902	}

904	/// Ensure `origin` is root or `para_id` itself.
905	fn ensure_root_or_para(
906		origin: frame_system::pallet_prelude::OriginFor<T>,
907		para_id: ParaId,
908	) -> DispatchResult {
909		if frame_system::ensure_root(origin.clone()).is_ok() {
910			return Ok(());
911		}
912		let id = T::ParachainOrigin::ensure_origin(origin)?;
913		ensure!(id == para_id, Error::<T>::NotOwner);
914		Ok(())
915	}

917	/// Store `info`, back to [`RegistrationState::Reserved`] after its registration fell through.
918	/// A system id is dropped instead, as only [`Pallet::force_register`] may register one.
919	fn store_reserved(para_id: ParaId, info: ParaInfoOf<T>) {
920		if Self::is_system(para_id) {
921			Self::release_or_report(info.reservation, &info.manager, para_id);
922			Paras::<T>::remove(para_id);
923		} else {
924			Paras::<T>::insert(para_id, info);
925		}
926	}

928	/// Report a failed defensive check: loud in the logs, and visible on chain.
929	fn report_unexpected(kind: UnexpectedKind) {
930		log::error!(target: "runtime::registrar-para", "unexpected: {kind:?}");
931		Self::deposit_event(Event::Unexpected(kind));
932	}

934	/// Drop `ticket` without failing: the relay chain already acted on the answer being applied.
935	fn release_or_report<C: Consideration<T::AccountId, Footprint>>(
936		ticket: Option<C>,
937		who: &T::AccountId,
938		para_id: ParaId,
939	) {
940		let Some(ticket) = ticket else { return };
941		if let Err(error) = ticket.drop(who) {
942			Self::report_unexpected(UnexpectedKind::DepositNotReleased { para_id, error });
943		}
944	}

946	/// Take the id for the next message to the relay chain.
947	fn next_message_id() -> u64 {
948		NextMessageId::<T>::mutate(|next| {
949			let id = *next;
950			*next = next.wrapping_add(1);
951			id
952		})
953	}

955	/// Apply the relay chain's verdict on a registration.
956	///
957	/// A response about a para id we are not expecting one for is dropped rather than treated as a
958	/// dispatch error: erroring here would unwind the whole incoming message for something we can
959	/// do nothing about anyway. They are reported as [`Event::Unexpected`] instead.
960	fn on_register_response(para_id: ParaId, message_id: u64, outcome: Outcome) -> DispatchResult {
961		let Some(mut info) = Paras::<T>::get(para_id) else {
962			Self::report_unexpected(UnexpectedKind::RegisterResponseForUnknownPara {
963				para_id,
964				message_id,
965			});
966			return Ok(());
967		};
968		let RegistrationState::Pending { ticket, message_id: expected, .. } = info.state else {
969			Self::report_unexpected(UnexpectedKind::RegisterResponseNotPending {
970				para_id,
971				message_id,
972			});
973			return Ok(());
974		};
975		if message_id != expected {
976			Self::report_unexpected(UnexpectedKind::StaleResponse {
977				para_id,
978				message_id,
979				expected,
980			});
981			return Ok(());
982		}
983
984		let manager = info.manager.clone();
985		match outcome {
986			Ok(()) => {
987				info.state = RegistrationState::Registered { ticket };
988				Paras::<T>::insert(para_id, info);
989				Self::deposit_event(Event::Registered { para_id, message_id, manager });
990			},
991			Err(reason) => {
992				Self::release_or_report(ticket, &manager, para_id);
993				info.state = RegistrationState::Reserved;
994				Self::store_reserved(para_id, info);
995				Self::deposit_event(Event::RegistrationFailed {
996					para_id,
997					message_id,
998					manager,
999					reason,
1000				});
1001			},
1002		}
1003
1004		Ok(())
1005	}

1007	/// Lock a para the relay chain has seen produce a head.
1008	fn on_head_noted(para_id: ParaId) -> DispatchResult {
1009		let Some(mut info) = Paras::<T>::get(para_id) else {
1010			Self::report_unexpected(UnexpectedKind::HeadNotedForUnknownPara { para_id });
1011			return Ok(());
1012		};
1013
1014		if info.locked.is_some() {
1015			return Ok(());
1016		}
1017
1018		if !matches!(info.state, RegistrationState::Registered { .. }) {
1019			Self::report_unexpected(UnexpectedKind::HeadNotedForUnregisteredPara { para_id });
1020		}
1021
1022		info.locked = Some(true);
1023		Paras::<T>::insert(para_id, info);
1024
1025		Self::deposit_event(Event::ParaLocked { para_id });
1026
1027		Ok(())
1028	}

1030	/// Apply the relay chain's answer to a cancellation.
1031	///
1032	/// `Ok(())` means the authorization is gone, so the deposit goes back. The one refusal is
1033	/// [`FailureReason::AlreadyRegistered`]: the code landed after all and the earlier verdict was
1034	/// simply lost, so the para is recorded as registered and the deposit stays held.
1035	///
1036	/// Unlike a register response, an answer for a para that is no longer pending is expected
1037	/// rather than unexpected: a verdict already in flight when the cancellation was sent settles
1038	/// the registration first, and this then has nothing left to do.
1039	fn on_cancel_response(para_id: ParaId, message_id: u64, outcome: Outcome) -> DispatchResult {
1040		let Some(mut info) = Paras::<T>::get(para_id) else {
1041			Self::report_unexpected(UnexpectedKind::CancelResponseForUnknownPara {
1042				para_id,
1043				message_id,
1044			});
1045			return Ok(());
1046		};
1047		let RegistrationState::Pending { ticket, message_id: expected, .. } = info.state else {
1048			log::debug!(
1049				target: "runtime::registrar-para",
1050				"cancel response for para {para_id} which is no longer pending, dropping",
1051			);
1052			return Ok(());
1053		};
1054		if message_id != expected {
1055			Self::report_unexpected(UnexpectedKind::StaleResponse {
1056				para_id,
1057				message_id,
1058				expected,
1059			});
1060			return Ok(());
1061		}
1062
1063		let manager = info.manager.clone();
1064		match outcome {
1065			Ok(()) => {
1066				Self::release_or_report(ticket, &manager, para_id);
1067				info.state = RegistrationState::Reserved;
1068				Self::store_reserved(para_id, info);
1069				Self::deposit_event(Event::RegistrationCancelled { para_id, message_id, manager });
1070			},
1071			Err(FailureReason::AlreadyRegistered) => {
1072				info.state = RegistrationState::Registered { ticket };
1073				Paras::<T>::insert(para_id, info);
1074				Self::deposit_event(Event::Registered { para_id, message_id, manager });
1075			},
1076			// Nothing else is a cancellation the relay chain refuses, so leave the registration
1077			// pending: the manager can ask again once the deadline comes round.
1078			Err(reason) => {
1079				Self::report_unexpected(UnexpectedKind::CancelRefused {
1080					para_id,
1081					message_id,
1082					reason,
1083				});
1084			},
1085		}
1086
1087		Ok(())
1088	}
1089
1090	/// Apply the relay chain's verdict on a deregistration.
1091	///
1092	/// `Ok(())` releases every consideration and the entry with them; a refusal puts the para back
1093	/// to [`RegistrationState::Registered`].
1094	fn on_deregister_response(
1095		para_id: ParaId,
1096		message_id: u64,
1097		outcome: Outcome,
1098	) -> DispatchResult {
1099		let Some(mut info) = Paras::<T>::get(para_id) else {
1100			Self::report_unexpected(UnexpectedKind::DeregisterResponseForUnknownPara {
1101				para_id,
1102				message_id,
1103			});
1104			return Ok(());
1105		};
1106		let RegistrationState::Deregistering { ticket, message_id: expected, .. } = info.state
1107		else {
1108			Self::report_unexpected(UnexpectedKind::DeregisterResponseNotDeregistering {
1109				para_id,
1110				message_id,
1111			});
1112			return Ok(());
1113		};
1114		if message_id != expected {
1115			Self::report_unexpected(UnexpectedKind::StaleResponse {
1116				para_id,
1117				message_id,
1118				expected,
1119			});
1120			return Ok(());
1121		}
1122
1123		let manager = info.manager.clone();
1124		match outcome {
1125			Ok(()) => {
1126				Self::release_or_report(ticket, &manager, para_id);
1127				Self::release_or_report(info.reservation, &manager, para_id);
1128				Paras::<T>::remove(para_id);
1129				Self::deposit_event(Event::Deregistered { para_id, message_id, manager });
1130			},
1131			Err(reason) => {
