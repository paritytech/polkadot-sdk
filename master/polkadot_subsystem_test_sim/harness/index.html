Source
Expand description

The harness layer: Sim struct, observation recorder, query dispatcher.

Subsystem-agnostic. Per-subsystem consumers provide a SubsystemUnderTest adapter; the harness’s Arc<MockClock> is passed to the subsystem directly (it impls Clock).
